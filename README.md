# WeatherDash – Real-Time Weather Dashboard

WeatherDash is a full-stack web application that delivers real-time weather forecasts. The system retrieves live meteorological data to provide current, hourly, and seven-day forecasts for locations worldwide.

## Core Features

- Worldwide city search capability featuring a dynamic dropdown menu.
- Browser geolocation integration for automatic local forecast retrieval.
- Display of current conditions, hourly variations, and seven-day forecasts.
- Functionality to save and concurrently compare multiple locations.
- Temperature unit toggling between Celsius and Fahrenheit.

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS, Axios
- Backend: Java, Spring Boot (Microservices Proxy)
- External API: Open-Meteo API
